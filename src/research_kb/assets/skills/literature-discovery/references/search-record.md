# Dated search record

Record date, question, sources, query concepts/filters, result counts or pages screened, deduplication keys, and coverage limits. Each shortlist item includes title, authors, year, stable identifier, local citekey if present, source link, ranking reason, and evidence mode (`metadata-only`, `abstract`, or `full-text`). For project gaps, name the goal/scope statement supported and what existing work it complements or challenges.
