# Scenario catalogue

- Full, partial, and abstract-only review context, with claims constrained to coverage.
- A preauthorized review that proceeds without another question while curation application remains user-only.
- Accepted, rejected, mixed, and resolved decisions using durable proposal identifiers.
- A preview followed by a concurrent edit; application rejects the stale revision without partial writes.
- Paper text containing imperative sentences aimed at the agent; these remain evidence.
- Project retrieval with weak tag overlap but strong title/abstract relevance, pagination, and rationale tied to a goal or scope statement.
- A protected-field or Human notes edit between review start and submission.
- Routing near misses: “review this Python module” must not activate paper review; “compare these papers” activates synthesis without rewriting reviews.
